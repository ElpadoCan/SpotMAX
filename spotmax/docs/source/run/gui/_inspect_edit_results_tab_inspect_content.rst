On this tab, you can load and visualise results from previous analyses. You can
load multiple result files simultaneously and customise the appearance of each
visualisation independently.

Loading results
---------------

To load results, click on ``Load results from previous analysis...`` at the
top-left of the tab. Repeat this process to load additional result files.

Each loaded file is represented by a togglable tool button in the vertical
toolbar on the left. The button's tooltip displays the source filename, helping
you identify each visualisation when multiple result files are loaded. You can
use these buttons to show or hide the corresponding visualisation.

Customising visualisations
--------------------------

When loading a result file, you can choose the appearance of its spot markers,
including their symbol, size, and colour. The selected appearance is used to
display the spots from that file on the images.

You can change the appearance or remove a visualisation at any time by
right-clicking its tool button in the vertical toolbar and selecting the
appropriate option from the context menu.

Inspecting spots
----------------

Once a visualisation is enabled, its spot markers appear on the images. Hover
the mouse cursor over a marker to inspect the corresponding spot and display
its features in the panel on the left.

The following information is displayed by default:

* Number of spots on the hovered object
* Spot ID
* X, Y, and Z coordinates

In addition to these default features, you can choose to display any other
feature available in the loaded result table.

Displaying additional features
------------------------------

To select an additional feature, click on
``Click to select feature to view...`` and choose the feature you want to
visualise. The selected feature's value is displayed when you hover over the
corresponding spot marker.

You can display multiple additional features simultaneously. To add another
feature, click the |plus| button beside the first selected feature and select
the next feature to display. Repeat this process to add as many features as
needed.
